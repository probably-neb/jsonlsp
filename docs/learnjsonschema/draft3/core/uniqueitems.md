# uniqueItems

- Original: [https://www.learnjsonschema.com/draft3/core/uniqueitems/](https://www.learnjsonschema.com/draft3/core/uniqueitems/)
- Upstream source: [https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/draft3/core/uniqueItems.markdown](https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/draft3/core/uniqueItems.markdown)
- Specification: [https://json-schema.org/draft-03/draft-zyp-json-schema-03.pdf#5.15](https://json-schema.org/draft-03/draft-zyp-json-schema-03.pdf#5.15)
- Metaschema: `http://json-schema.org/draft-03/schema#`
- Introduced in: `draft2`

If this keyword is set to the boolean value `true`, the instance validates successfully if all of its elements are unique.
