# Unevaluated

- Original: [https://www.learnjsonschema.com/2020-12/unevaluated/](https://www.learnjsonschema.com/2020-12/unevaluated/)
- Upstream source: [https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/2020-12/unevaluated/_index.markdown](https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/2020-12/unevaluated/_index.markdown)
- Specification: [https://json-schema.org/draft/2020-12/json-schema-core.html#section-11](https://json-schema.org/draft/2020-12/json-schema-core.html#section-11)
- Metaschema: `https://json-schema.org/draft/2020-12/meta/unevaluated`

A mandatory vocabulary that defines keywords that apply subschemas to array items or object properties that have not been successfully evaluated against any dynamic-scope subschema of any adjacent keywords.
