# Core

- Original: [https://www.learnjsonschema.com/2020-12/core/](https://www.learnjsonschema.com/2020-12/core/)
- Upstream source: [https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/2020-12/core/_index.markdown](https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/2020-12/core/_index.markdown)
- Specification: [https://json-schema.org/draft/2020-12/json-schema-core.html#section-8](https://json-schema.org/draft/2020-12/json-schema-core.html#section-8)
- Metaschema: `https://json-schema.org/draft/2020-12/meta/core`

A mandatory vocabulary that defines keywords that are either required in order to process any schema or meta-schema, including those split across multiple documents, or exist to reserve keywords for purposes that require guaranteed interoperability.
