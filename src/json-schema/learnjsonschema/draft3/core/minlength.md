- Upstream source: [https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/draft3/core/minLength.markdown](https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/draft3/core/minLength.markdown)
- Specification: [https://json-schema.org/draft-03/draft-zyp-json-schema-03.pdf#5.17](https://json-schema.org/draft-03/draft-zyp-json-schema-03.pdf#5.17)
- Metaschema: `http://json-schema.org/draft-03/schema#`
- Introduced in: `draft1`

A string instance is valid against this keyword if its length is greater than, or equal to, the value of this keyword.
