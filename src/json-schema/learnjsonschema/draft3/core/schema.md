# $schema

- Original: [https://www.learnjsonschema.com/draft3/core/schema/](https://www.learnjsonschema.com/draft3/core/schema/)
- Upstream source: [https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/draft3/core/schema.markdown](https://raw.githubusercontent.com/sourcemeta/learnjsonschema.com/main/content/draft3/core/schema.markdown)
- Specification: [https://json-schema.org/draft-03/draft-zyp-json-schema-03.pdf#5.29](https://json-schema.org/draft-03/draft-zyp-json-schema-03.pdf#5.29)
- Metaschema: `http://json-schema.org/draft-03/schema#`
- Introduced in: `draft3`

This keyword is both used as a JSON Schema dialect identifier and as a reference to a JSON Schema which describes the set of valid schemas written for this particular dialect.
We are looking for contributors to help us fully expand the documentation to
cover this dialect. If that sounds like you, [send a pull
request on GitHub](https://github.com/sourcemeta/learnjsonschema.com/pulls)!
